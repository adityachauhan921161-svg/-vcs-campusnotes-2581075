\# How to Use CampusNotes



\## Getting Started



1\. Clone the repository.

2\. Open the CampusNotes folder.

3\. Read README.md to understand the project.

4\. Use notes.txt to store academic notes.

5\. Use subjects.txt to organize subject names.

6\. Read study-tips.txt for study suggestions.



\## Git Commands



Check repository status:



git status



View commit history:



git log --oneline



Pull latest changes:



git pull origin main
